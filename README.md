# Master's Degree in Quantum Computing (UNIR)

Repository with coursework and assignments from the Master's Degree in Quantum Computing at Universidad Internacional de La Rioja (UNIR).

## Repository structure

Each folder corresponds to an assignment from a course in the program:

| Folder | Course                     | Assignment   |
| ------ | -------------------------- | ------------ |
| `AL1/` | Linear Algebra             | Assignment 1 |
| `AL2/` | Linear Algebra             | Assignment 2 |
| `CC1/` | Quantum Computing          | Assignment 1 |
| `CC2/` | Quantum Computing          | Assignment 2 |
| `IC1/` | Quantum Information        | Assignment 1 |
| `IC2/` | Quantum Information        | Assignment 2 |
| `MC1/` | Quantum Mechanics          | Assignment 1 |
| `MC2/` | Quantum Mechanics          | Assignment 2 |
| `MI1/` | Mathematics of Information | Assignment 1 |

## Contents

Each assignment includes:

- LaTeX documents with problem solutions
- Jupyter notebooks (where applicable)
- Figures and auxiliary resources
